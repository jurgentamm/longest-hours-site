Privacy policy: Longest Hours uploader

Last updated: 12 November 2026.

Longest Hours uploader is a personal tool used only by the owner of The Longest Hours YouTube channel. It uses the YouTube Data API to upload the channel's own videos, thumbnails and playlist entries.

  • It accesses only the owner's own YouTube channel, with the owner's consent.
  • It does not collect, store, sell or share any personal data of anyone else.
  • The access token is stored only on the owner's own computer and can be revoked at any time at myaccount.google.com/permissions.

Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
